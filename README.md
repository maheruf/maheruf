## 👨‍💻 About Me

- 🔭 Currently studying and building projects with **JavaScript**, **TypeScript**, and modern web frameworks.
- ⚙️ I enjoy configuring network hardware with **OpenWrt**, including multi-WAN load balancing and failover.
- 🤖 I experiment with running **local LLMs** using tools such as **llamafile** on custom hardware.
- 🎯 My long-term goal is to become a **Full-Time Game Developer**.
- 🎮 I was an **Alpha Tester for Men of War II**, providing feedback on UI/UX, gameplay, bugs, and sound.
- 🛠️ I create **Steam community mods** for GEM Engine games, including *Men of War II*, *Call to Arms*, and *Call to Arms - Gates of Hell: Ostfront*.
- 📝 I use **Notion** and **Discord** for programming notes and revision.
- 📬 Reach me at **maheruf.dev@gmail.com**
